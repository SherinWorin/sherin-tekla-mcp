### Relationship to Wall Framing Layout

Each SECTIONAL ELEVATION corresponds to a WALL FRAMING LAYOUT drawing:
- BP01 Sectional Elevation [95] ↔ BP01 Wall Framing Layout [135] (or [50])
- BP01M Sectional Elevation [96] ↔ BP01M Wall Framing Layout [136]
- BP02 Sectional Elevation [97] ↔ BP02 Wall Framing Layout [139]
- ...and so on for all 19 pairs

**Section Cut Lines** on the Wall Framing Layout define where the SectionViews are cut.

## Part 3: Macro Development Plan

### Macro 1: ISOMETRIC VIEW Generator
**Target:** GA drawings with Title2 = "ISOMETRIC VIEW"
**Input:** Block identifier from Title1
**Output:** 3 isometric ModelViews with correct orientations and color coding
**Reference:** Drawing [115] (BP01-80001)

**Required from manual inspection:**
- 3 view orientations (direction vectors)
- Color coding scheme per element type/class/material

### Macro 2: SECTIONAL ELEVATION Generator
**Target:** GA drawings with Title2 = "SECTIONAL ELEVATION"
**Input:** Block identifier, section cut lines from corresponding WALL FRAMING LAYOUT
**Output:** 5-6 SectionViews with dimensions, text notes, level marks
**Reference:** Drawing [95] (BP01-20001)

**Key Logic:**
1. Find corresponding WALL FRAMING LAYOUT drawing
2. Read section marks (SectionMark objects) from that drawing
3. Create SectionView for each section mark
4. Place SectionViews on sheet in standard layout
5. Add standard dimensions and text notes per section type

### Macro 3: CEILING FRAMING LAYOUT Generator
**Target:** Assembly drawings named "CEILING_FRAME"
**Input:** Block identifier, ceiling assemblies for the block
**Output:** Assembly drawing with ceiling framing views
**Reference:** [BP1-CF.1] through [BP10M-CF.1]

**Key Logic:**
1. Find ceiling assemblies for the block (prefix CEILING_FRAME)
2. Create assembly drawing
3. Add views showing ceiling beams, tracks, gypsum
4. Add dimensions and marks

## API Members Confirmed

### SectionView Creation
- `View.CreateSectionView(viewCoordinateSystem, viewScale, depthUp, depthDown, startPoint, endPoint, viewRotationAngle)`

### View Types Available
- `ViewType.ModelView` (for isometric)
- `ViewType.SectionView` (for sectional elevation)
- `ViewType.DrawingView` (for plan views)

### Annotations
- `StraightDimensionSet` for dimensions
- `Mark` for part/assembly marks
- `Text` for notes
- `SectionMark` for section cut lines
